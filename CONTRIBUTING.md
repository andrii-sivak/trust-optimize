# Contributing

## Development setup

- Run `composer install` in the plugin directory.
- Checks: `composer run-script phpcs` and `composer run-script test:unit`.
- Release archives are built by `scripts/build-release.sh`. They contain only the tracked paths listed in `.gitattributes`; anything else, including a new file or directory, stays out until it is added there.

## AI-assisted workflow

None of the files below is part of the plugin release.

### WordPress agent skills

The project follows the official [WordPress agent skills](https://github.com/WordPress/agent-skills). They are tracked in git, so they work right after a clone: `.claude/skills/`, `.agents/skills/` and `.junie/skills/` hold copies of the same skills, and `skills-lock.json` pins the source commit.

Update them with the `skills` CLI and commit the result:

```
npx skills update
```

To add one, run `npx skills add WordPress/agent-skills --skill <name> --agent claude-code codex antigravity junie --copy`.

### BMAD

The project uses the [BMAD Method](https://github.com/bmad-code-org/BMAD-METHOD) for planning and AI-assisted development.

What is tracked in git:

- `_bmad/` – the BMAD installation: module configs, scripts, and the manifest (`_bmad/_config/manifest.yaml`) with the installed version, modules and tools.
- `_bmad-output/` – planning and implementation artifacts (briefs, PRDs, architecture, specs, stories).
- `info/` – project knowledge that the agents read as context.

What is not tracked and is regenerated by the installer:

- the BMAD skill copies for each AI tool: `bmad-*` in `.claude/skills/`, `.agents/skills/` and `.junie/skills/`, and `.agent/`;
- personal files: `_bmad/config.user.toml`, `_bmad/custom/*.toml`, `.claude/settings.local.json`.

You need the BMAD skills only if you want to use the BMAD agents and workflows. Run the installer in the plugin directory:

```
npx bmad-method install
```

Choose the version and modules listed in `_bmad/_config/manifest.yaml` and the AI tools you use. The installer reuses `_bmad/config.toml` and writes your personal answers to `_bmad/config.user.toml`.
